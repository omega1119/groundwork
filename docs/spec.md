# Spec

Replace this file with the spec for the actual project, using
[`templates/spec.template.md`](../templates/spec.template.md). The `spec-first` skill or
the `/write-spec` prompt will do it for you.

Until then, this file is a reminder that the spec comes before the code when the work is
bigger than one sitting. The two sections that carry the weight:

- **Success criteria** someone else can check. "Ranks 10,000 rows in under 5 minutes" can
  be checked. "Fast and reliable" cannot.
- **Non-goals**, what this deliberately does not do. This is the section that stops the
  scope growing, and the one most often left out.

Choices that would be expensive to reverse get a short record in
[`decisions/`](decisions/), so nobody re-litigates them in six months.
